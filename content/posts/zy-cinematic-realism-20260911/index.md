我之前在博客里写过一篇《AI 画图让我学会看光》。

那时候我最大的体会是：出图很快，但出“像样的图”很难。

为了让生成的图显得“高级”、“有质感”，很多人——包括曾经的我——都走过同一段弯路：在 Prompt 里疯狂堆砌词藻。从 `8K`、`masterpiece`、`虚幻5渲染`，到后来的 `丁达尔神光`、`边缘轮廓蓝光`、`电影感大片`、`胶片颗粒`。

然而结果往往很令人沮丧：画面依然泛着一股浓浓的“AI 塑料味”与“影楼摆拍感”。人物眼神空洞，阴影方向莫名其妙，整张画面像是一张商业促销海报，缺乏呼吸感与生活痕迹。

最近在看开源项目 [zy-cinematic-realism](https://github.com/popopo-99/zy-cinematic-realism)（对外品牌名是 **「造梦师 / DREAM DIRECTOR」**），它在 README 结尾写了这样一句话：

> **“先让画面成为故事中的一个真实瞬间，再考虑它使用什么镜头和胶片。”**

这句话几乎精准戳中了当前绝大部分 AI 图像生成的痛点。

它不是一个新的大模型，也不是一包廉价的“万能胶囊词”。它是一套运行在 ChatGPT / Codex 上的**电影视觉系统与提示词编译框架**。

---

## 核心反差：从“词藻堆砌”到“单一事实源”

传统写 Prompt 的思维通常是线性的、一次性的：

```text
脑中模糊的想法 ──> 塞进一大堆修饰词 ──> 抽卡赌运气 ──> 失败了全盘重来
```

《造梦师》升级到 v2.0 及最新的 v2.1.1 之后，把这个过程重构成了一条极具软件工程美感的编译管线：

```text
               用户的一句原始念头
                      │
                      ▼
            ┌───────────────────┐
            │   Scene Master    │  <-- 唯一事实源（人物/叙事瞬间/物理空间/动机光）
            └─────────┬─────────┘
                      │
                      ▼
            ┌───────────────────┐
            │ Creative Grammar  │  <-- 摄影调度 / 导演四轴指纹
            └─────────┬─────────┘
                      │
                      ▼
           ┌─────────────────────┐
           │   Model Compiler    │  <-- 编译器管线
           └──┬───────┬───────┬──┘
              │       │       │
              ▼       ▼       ▼
         GPT Image 2.5   Midjourney V8.2   Seedream 5.0 Pro ...
```

官方提炼了一条黄金法则：

> **MODEL SYNTAX MAY CHANGE. SCENE LOGIC MAY NOT.**  
> （模型语言可以改变，画面设计不能偷偷改变。）

这就是非常经典的**解耦（Decoupling）思想**：

以往你想把 Midjourney 跑通的 Prompt 搬到 GPT Image 2.5 或国内其他模型，往往只能全盘重构。因为不同模型对词性密度、自然语言叙述、负向词支持、参数顺序的偏好天差地别。

而《造梦师》将**“画面在物理和故事上到底发生了什么”**与**“如何向特定模型表达这个意图”**彻底拆分。

`Scene Master` 是画面唯一的真相（Single Source of Truth），牢牢锁死叙事动作、机位视角、空间拓扑与主光源；至于转成目标模型时需要用短语还是完整句子、参数放在哪、排除项怎么写，全部交给后端的 `Model Compiler` 解决。

## 电影感的底层：五个反直觉的物理原则

为什么《造梦师》调教出来的画面，能迅速洗掉那种廉价的“AI 油腻感”？阅读它的原则规范与 Anti-AI 清单，会发现它总结了五条非常扎实的底层规律。

### 1. 叙事大于摆拍：抓取“余波”与“等待”

一般的 Prompt 习惯把人物当成静止模特：
> *弱描述：“一个侦探站在雨后的纽约街头。”*

《造梦师》的工作流会要求赋予它一段具体的时间切片：
> *强描述：“最后一辆巡逻车开走后，侦探依然停留在卷帘门紧闭的杂货店外，手里握着一杯已经凉透的外卖咖啡，没有看镜头。”*

它刻意偏爱**等待、事后（aftermath）、迟疑、被打断的日常、离去**。因为真正耐看的电影画面，永远在画框之外藏着“上一秒刚发生了什么”的因果，以及“下一秒将走向何处”的未知。

### 2. 摄像机必须拥有“物理目击机位”

在许多 AI 生成图里，镜头是漂浮在空气中的上帝视角。《造梦师》要求镜头必须属于同一个物理现实：

- 半掩的门扇后面；
- 夜班公交车的最后一排座垫缝隙；
- 隔着公交车站满是水雾的防风挡板；
- 停在路边的轿车后座；
- 紧贴着潮湿沥青路面的低机位。

机位有了真实的“物理站位”，画面的遮挡、裁切、虚焦和反光才会自然产生，而不是被算法硬生生贴上去的。

### 3. 环境必须承载因果证据（Causal Evidence）

它有一条严厉的构图审查标准：

> **“如果把画面中的人物瞬间抽离，剩下的空镜头依然能让人看出这里刚才经历了什么。”**

- 椅子脚下散落的水渍与挂着的湿雨衣（刚淋过大雨）；
- 翻倒的收据与未喝完的冷饮（一场戛然而止、不欢而散的谈话）；
- 座椅皮革边缘裂开露出的海绵与褪色的检修标签（长期高密度的公共使用）。

因果痕迹胜过一万个无意义的“精美杂物”。

### 4. 动机光源（Motivated Light）：凡光必有出处

这是我个人最深有共鸣的一点。

AI 模型最喜欢冷不丁在角色后背勾勒一条炫酷的“亮蓝轮廓光”，或者凭空射入几道耀眼的金色体积神光。《造梦师》明确禁止这类无源之光。在描述光线时，必须先回答：

- 场景内的**主光源**是什么？（是头顶闪烁的破损荧光灯管，还是小店透出来的暖黄卤素灯？）
- **次级/间歇光源**是什么？（是掠过的出租车尾灯，还是远处跳动的霓虹招牌？）
- 阴影在何处自然积聚？高光由什么材质的表面反射？

光必须为空间服务。没有来源的光，就是廉价的塑料包装纸。

### 5. 克制检验（Restraint Test）与反 AI 清理

它的自检标准极其干脆：

> **如果把提示词里的 `cinematic`、相机牌子、胶片型号、画质形容词全部剔除，这个画面在结构上依然成立吗？**

在它的反向清理（Anti-AI Cleanup）清单里，被列为“毒药”的恰恰是很多人习以为常的东西：
- 全身光滑无瑕的蜡质皮肤；
- 全景等深、每一处砖缝都被过度锐化的“纹理浓汤”；
- 像开了 HDR 一样毫无死角的暗部细节；
- 刻意美化、充满摆拍痕迹的“做旧工业风”。

《造梦师》主张保留未经雕琢的哑光表面、允许非视觉中心沉入自然的死黑、允许次要物体模糊不可辨。**敢于不讨好观众的眼睛，画面才能换来真实的信服力。**

## 导演系统：拒绝“贴标签”，推行“四轴指纹”

如果你在常规 Prompt 里加上一句 `in Wong Kar-wai style`（王家卫风格），模型往往只会给你输出抽帧模糊、黄绿高饱和以及穿旗袍的刻板符号。

《造梦师》内置了庞大的导演库（包括王家卫、贾樟柯、毕赣、娄烨、刁亦男、张艺谋、杨德昌、侯孝贤、黑泽明、岩井俊二、大卫·芬奇、维伦纽瓦等）。

但它规定：**绝不把导演名字当成偷懒的滤镜标签。**

一旦引入某位导演，必须将其强制解构成四条具体的**物理指纹**：

```text
┌────────────────────────────────────────────────────────┐
│               导演四轴视觉指纹 (Four-Axis)               │
├────────────────────────────┬───────────────────────────┤
│ 1. 光影与对比度指纹         │ 动机光源、硬软光比、暗部保留 │
│ 2. 色彩与曝光指纹           │ 材质固有色、色温对冲、曝光宽容│
│ 3. 镜头与机位指纹           │ 物理视点、焦段几何、运动视差 │
│ 4. 构图与空间指纹           │ 纵深遮挡、人景调度、留白比例 │
└────────────────────────────┴───────────────────────────┘
```

比如调用**刁亦男**时，触发的是：夜间孤立的硬光源、带有脏污感的夜市混合色温、被公共设施结构切割的中远景、以及把危机感隐匿于市井琐碎的疏离观察；调用**毕赣**时，触发的则是湿润漫射的高光溢出、被亚热带水汽污染的色彩、跟随式移动视点，以及多重嵌套的记忆迷宫。

这相当于用专业电影视听语言，直接把大模型当成了懂场面调度的执行摄影师。

## 为什么说它是一个“严肃的工程项目”

作为一个长期折腾开发工具的人，看《造梦师》最让人兴奋的，是它骨子里透出来的工程严谨性：

1. **单向数据流**：从 Scene Master 锁定事实，到 Creative Grammar 注入美学，再到 Model Compiler 产生各端代码，层次分明。
2. **靶向修复（Prompt Doctor / One Variable Remix）**：生成的画面不理想时，绝不推倒重写。它能锁定全部原有变量，只针对出问题的单个属性（如机位高度或主光源位置）进行局部手术式的指令修正（`CHANGE ONLY` 与 `PRESERVE EXACTLY`）。
3. **连续性圣经（Continuity Bible）**：为多镜头连续组图建立人物面容、服装损耗、道具形态与地理拓扑的约束锚点，解决了一直以来 AI 分镜“一换镜头就换了个人”的顽疾。

这不再是停留在“试咒语”阶段的散兵游勇，而是一套运行在自然语言之上的特定领域编译器（Domain-Specific Compiler）。

## 总结

AI 画图演进到今天，算力越来越充裕，模型参数越来越大，细节甚至能算清每一粒毛孔。但真正能打动人的画面，依然少之又少。

《造梦师》给出了一个清醒的答案。

它告诉我们：**高级的电影感不是一种滤镜，也不是昂贵器材型号的罗列，而是一套对物理世界充满敬畏的观看方式。**

你得先明白夕阳斜射穿过百叶窗时阴影会落在哪块地板上；得明白一个疲惫不堪的人为什么眼神不会聚焦在镜头正中央；得懂得老旧墙皮的剥落是伴随着水汽侵蚀的重力轨迹——当你把这些真实的因果交还给画面，AI 才能停止廉价的幻想，吐出真正具有重量和呼吸感的瞬间。

它表面上是一套写 Prompt 的工具，内里却是一场教我们重新学会“凝视真实”的审美实践。
